# Maine-yball

> Revealing the true stories of Maine sports, beyond the logos, narratives, and noise.

Maine-yball is a sports analytics platform built using Python and Streamlit to analyze Maine high school athletics through data-driven rankings, visualizations, and predictive models.

## Current Features

- Maine-yball Power Index (MPI)
- Team comparison
- Football analytics
- Hockey framework
- Interactive dashboard

## Built With

- Python
- Streamlit
- Pandas
